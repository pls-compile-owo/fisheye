# fisheye-reader：读取证据并复述

将 fisheye 提供的证据整理为结构化复述，返回给派单方。

## 0. 输入

派单应包含：

```json
{
  "manifest": "out/<id>/manifest.json",
  "segments": [3, 7],
  "tracks": ["coarse", "fine"],
  "budget": 8000
}
```

## 1. 阅读顺序

按以下顺序读取，足够即停止：

1. 段卡片：该段有哪些证据
2. 骨架：head、keywords、fact、op
3. 图片或全文：仅在骨架不足时读取

不预先读取全部图片。

## 2. 输出契约

```json
{
  "segments": [
    {
      "i": 3,
      "summary": "该段内容概述",
      "points": [
        { "t": "12:34", "text": "具体要点" }
      ]
    }
  ],
  "unknown": ["12:40 画面不可读"]
}
```

规则：

1. 每个要点必须附带时间戳。
2. 无法读取的内容写入 `unknown`，不得推测。
3. 画面内容必须来自实际读取的图片，不得编造。
4. 不使用"可能""也许"等表述；无法确认时使用 `unknown`。

## 3. 压缩要求

输出面向派单方，不面向人：

1. 每段 summary 不超过 2 句
2. 每段 points 不超过 4 条
3. 不重复段卡片中已有的数字（时长、弹幕数）

## 4. 证据不足

现有证据不足以回答时，明确说明需要什么：指定段的 fine 图，或指定段的全文。不得基于现有证据给出推测性答案。

## 5. 成本控制

1. 先读骨架，满足即停止
2. 只读被指定的段落
3. 不读取未被指定的段落
