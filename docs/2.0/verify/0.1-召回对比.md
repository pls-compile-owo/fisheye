# 0.1 两路 vs 七路广告召回（第 0 批验证）

> 核对时间：2026-11-18。用 27 条人工真值（`test/golden/low-activity/`，第 3 批由 `ad-truth/` 改名）离线对比「七路」与「两路」广告召回。
> 脚本：`tools/verify-2.0-0.1-recall.mjs`（可复跑）。

## 一、口径定义

- **七路** = 1.0.29 全部 7 个信号源：density / keywords / mark / head / buy / sub-keywords / sub-patterns。
- **两路** = 2.0 保留的 density + keywords（`adKeywordHits` 纯线索另计）。
- 召回命中 = 检测段与 `truthAdSegments` 的 overlap ≥ 0.8（与 `golden.test.mjs` 一致）。
- 两种口径：`high-only`（只看关键词命中段）与 `all`（high+low 全算，= 2.0 两路完整产出）。

## 二、总体结果

有广告样本 14 条（非 hardCase）/ truth 段 14 个：

| 口径 | 七路召回 | 两路召回 | 两路/七路 |
|---|---|---|---|
| high-only | 64%（9/14） | 64%（9/14） | **100%** |
| **all（=2.0 两路）** | **100%（14/14）** | **100%（14/14）** | **100%** |

- 无广告样本 10 条：七路/两路 high 误报均 **0**（精确率一致）。
- hardCase 3 条（虎门抽烟 / 破产大王 / 千万别和老番茄…）：两路与七路表现一致（不参与召回考核）。

## 三、分组

| 分组 | 七路（all） | 两路（all） | 比值 |
|---|---|---|---|
| 正常文本 9 条 | 100%（9/9） | 100%（9/9） | 100% |
| 乱码清空（仅密度）5 条 | 100%（5/5） | 100%（5/5） | 100% |

- 乱码样本（弹幕文本已清空，只剩时间戳）的召回全部来自 **density 密度低谷**——验证了 density 作为「低活跃检测」核心信号的独立召回能力。
- 逐条对比显示：七路里的 mark/head/buy/sub-keywords/sub-patterns 五路在 27 条真值上**零独立命中**（唯一差异是 BV1gGgk6hEU8 七路多产 1 个 high 段，但不提升召回）。

## 四、结论

1. **两路召回 = 七路召回（100% = 100%），远超验收线「≥80%」。**
2. **砍五路（mark/head/buy/sub-keywords/sub-patterns）安全**，零召回损失、零误报增加。
3. 支撑设计文档 05 §7.1「七路里真正干活的就两路」的复盘结论，第 3 批广告重构可直接砍到两路。
4. 附带确认：density 信号的当前阈值（`median×0.45`、连续低谷 ≥45s）在乱码样本上召回正常，无需因本次验证调整（低活跃阈值留待第 3 批 `detectLowActivity` 实现时用 `FISHEYE_LOW_ACTIVITY_WEIGHT` 配置化）。
