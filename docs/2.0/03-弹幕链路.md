# 弹幕链路：情绪双分数

> 2.0 模块文档。总纲见 [00-总纲.md](./00-总纲.md)。

## 一句话

弹幕给"观众反应"这个看不见的证据：情绪浓不浓、在哪炸。**只给量级，不追求精确**——agent 会拿原始数兜底。

### 5.1 两个分数（不给判定）

```js
{
  subsEmotion:    { value: 0.012, level: 'low',  samples: 320, confidence: 'ok' },
  danmakuEmotion: {
    value: 0.16, level: 'high',
    samples: 20, unique: 11, dupRatio: 0.45,
    suspect: 'spam-heavy',          // dupRatio > 0.4
    confidence: 'low',              // <20 条
    top: [                          // 3 条代表性原文（去重后各取 1）
      { t: 4.3, text: '这是所有改版里最可爱的肥猫！' },
      { t: 1.4, text: '哈莎神之八秒' }
    ]
  }
}
```

| 字段 | 含义 |
|---|---|
| `value` | 情绪浓度（量级，不精确） |
| `level` | `high` / `low`（分位数 + 绝对下限） |
| `samples` / `unique` / `dupRatio` | 原始数（agent 想精确就自己算） |
| `suspect` | 异常标记（`spam-heavy` = 重复度过高） |
| `top` | **3 条代表性原文**（~40 token）——数字不可信时看这个 |
| `confidence` | 样本量决定（<20 条 → low） |

### 5.2 判定规则

```
level = (value > 全片中位数) && (value > floor) ? 'high' : 'low'

floor：danmaku 0.08 / subs 0.02   （占位值，需实测校准）
```

**绝对下限解决"全片平坦"陷阱**：分位数是相对的，全片都平淡时仍会有一半在中位数以上——加 floor 后，全低于下限就全判 low，不再强行二分。

### 5.3 情绪词分层（精度）

| 层 | 用在哪 | 例子 | 匹配规则 |
|---|---|---|---|
| **emotion**（纯情绪） | `subsEmotion` / `danmakuEmotion` | 哈哈哈 / 笑死 / ？？？ / ！！！ / 泪目 / 卧槽 | 独立成句或句尾，**不用单字** |
| **opinion**（观点） | `op`（字幕摘要） | 属于是 / 我请问 / 好家伙 / 绝了 / 草 / 牛 / 离谱 | 可子串，但需词边界 |

`草` / `牛` 属于**观点**（op），不算情绪——解决「草原→草」「牛顿→牛」的误报。

### 5.4 刷屏：√ 压缩而不是去重

```
同文本 n 次 → 贡献 √n（分子压缩，**分母仍用原始条数**）
  1 次 → 1
  4 次 → 2
  20 次 → 4.5
```

| 场景 | 完全去重 | √压缩 |
|---|---|---|
| 低弹幕量（20 条里 10 条"哈哈哈"） | 5%（严重低估） | **16%**（合理） |
| 集体玩梗（100 条里 20 条"哈基米"） | 1%（几乎消失） | **5%**（保留） |

**诚实边界**：弹幕 API 无用户 id，没法区分"一个人刷 20 次"和"20 个人各发 1 次"——√ 压缩是折中假设。`samples`/`unique` 让 agent 自己看原始重复度。

### 5.5 耦合映射（实测修正）

| 状态 | 含义 | agent 建议 |
|---|---|---|
| 都高 | **高潮段**（UP 激动 + 观众激动） | 两源都看 |
| 字幕高 / 弹幕低 | UP 在玩梗（观点多），观众冷静 | 看字幕 |
| 弹幕高 / 字幕低 | 观众在嗨，内容在讲事实 | 看字幕（事实在字幕） |
| **都低** | **平淡段**（过渡/铺垫） | 可降权 |

> "不重要"的判据是"都低"，不是"都高"——实测段 8（1972 大收购，全片最重要内容之一）就是"都高"。

### 5.6 缺失：null ≠ 0

- 无弹幕 → `danmaku: null`（不是 `emotion: 0`）
- <20 条 或 <0.05 条/s → `confidence: 'low'`（两个维度都要判）
- 单段 <5 条 → 该段 `danmaku: null`，其他段正常

### 5.7 实测参考（可汗 2255s，10 段）

| 段 | 内容 | 字幕情绪 | 弹幕情绪 |
|---|---|---|---|
| 5 | 吐槽段（祖坟核聚变） | 0.033（最高） | 0.052 |
| 8 | 1972 大收购 | 0.017 | 0.134（最高） |
| 2 | 火灾段 | 0 | 0.025 |

> 注：按新的词表分层，段 5 应归 **op（观点）** 而不是 subsEmotion（纯情绪）——这是分工后的判定变化。
