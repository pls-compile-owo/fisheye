# 字幕链路

> 2.0 模块文档。完整设计见 [字幕链路-设计.md](../字幕链路-设计.md)（含实测数据与算法细节），本文是摘要与索引。
> 总纲见 [00-总纲.md](./00-总纲.md)。

## 一句话

字幕是最大的一笔成本（40 分钟视频 49,757 token，占旧链路 53,557 的 93%）——2.0 把它压成「骨架给决策 + 全文给引用 + 翻译下游化」。

### 4.1 三档形态

| 档 | 内容 | 成本 | 用途 |
|---|---|---|---|
| 1 | 骨架（head/keywords/fact/op） | ~45~140/段 | 默认（决策用） |
| 2 | 全文（`seg-NN-subs.txt`） | ~5k/段 | 引用原话 |
| 3 | 字幕带图（烧录字幕） | ~1024/张 | 无文本字幕时兜底 |

### 4.2 摘要四铁律（实测校准）

1. 关键词用 **TF-IDF**（不是词频）
2. 停用词表完整（英文 200+，中文 200+）
3. **广告句踢出摘要**（复用 `adKeywordHits`）
4. head/info 截断 60 字（中）/110 字符（英）

### 4.3 两个额外判定

| 判定 | 判什么 | 依据 |
|---|---|---|
| **可压缩性** | 有没有可抽的信息（不是质量） | 平均句长 / 实词比 / 数字专名 / 句间连贯；**配 `sample`（抽出来的句子）** |
| **质量** | 字对不对 | 实词比 / 重复率 / 字数（覆盖官方/转写/字幕带三种来源） |

### 4.4 关键实测案例

- **转写遮挡字幕带**（BV1FVWU6wEnp）：转写"成功"12 字垃圾 → 跳过了字幕带检测 → 真字幕没读。修复方向：转写质量差时继续尝试字幕带（**待修，1.0.29 已确认**）。
- **可压缩性极限样本**（同视频）：字幕字全对但全是梗/拟声，摘不出信息 → `compressible: false`（字幕这个证据源无效，不等于视频无价值，价值在画面）。

### 4.5 语言与翻译

- 有翻译轨 → 抽中文摘要（49,757 → 11,615 → ~1.1k/9 段）
- 无翻译轨 → 英文摘要（术语保留原文）
- **翻译不进 fisheye**（下游化：B站 轨 / agent 自己 / 人用翻译软件）
